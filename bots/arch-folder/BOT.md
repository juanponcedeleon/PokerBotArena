# arch-folder (sparring archetype, not a candidate)

Models the practice round's tight folders (19 teams with VPIP <= 15%, 14-19 pts/table): opens only pairs 77+ / AK-x for 2.5 BB, never limps, calls raises only with TT+, shoves 77+/AK-x at <= 10 BB, folds everything else; postflop bets two pair+ and calls small bets with a pair. Use in `arena ab --field`. Created by Claude (keep-rule agent, branching out), 2026-11-06.
